# Session Review Checklist

- What did the user correct directly?
- What did the session reveal that was not obvious at the start?
- Which mistakes could be prevented by steering or a hook?
- Which repeated workflow belongs in a dedicated skill?
- Are there unresolved TODO or FIXME markers in changed files?
- What must the next session know immediately?
- Is there unfinished implementation work? If yes, recommend `handover`.
- Do any lessons apply across projects? If yes, flag for global steering.
