# Rust

Keep crates domain-driven.

Keep pure library crates free of runtime and framework dependencies unless the
crate's purpose is explicitly integration or platform glue.

When `lsp-rust` is configured, use it for definitions, references, diagnostics,
and safe renames before text search.

Use the project setup skill or [toolchain defaults](../toolchain-defaults/toolchain-defaults-index.context.md)
for cargo workspace, error handling, CLI, HTTP, async, and desktop defaults.
