# Session Review

Use this skill near the end of a session or before writing a handover.

## Steps

1. Identify user corrections and non-obvious discoveries from the session.
2. Check changed files for unresolved TODO or FIXME markers without corresponding issues.
3. Flag patterns that should become steering rules, hooks, or skills.
4. Summarize what should be carried forward versus dropped.
5. Save unsaved lessons to long-term memory.

## Output Format

Present findings as:
- **Corrections captured**: count
- **Lessons saved**: count
- **TODOs without issues**: list
- **Proposed improvements**: list (hook, skill, or steering rule per item)

## Steering

- Prefer actionable findings over narrative recap.
- Separate confirmed lessons from speculative improvement ideas.
- If a lesson applies broadly, flag it for promotion into global steering or a reusable skill.
