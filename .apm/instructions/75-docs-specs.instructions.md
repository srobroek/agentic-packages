# Docs And Specs

Split docs by purpose: architecture, decisions, research, runbooks, product,
engineering, operations, and API docs. Use Astro for marketing/content docs,
VitePress for technical docs, and Storybook for shared UI/design systems.

Use `specs/` in every project. Choose one Spec mode: no SpecKit with `specs/`
only, lightweight specs, or full Specify/SpecKit workflow.
